# DF002 — Telco Customer Churn Investigation

## Contexto

A DATAFORGE ANALYTICS foi acionada para investigar o aumento do churn de clientes em uma empresa do setor de telecomunicações.

A liderança executiva identificou crescimento nas taxas de cancelamento durante os últimos ciclos operacionais, levantando preocupações relacionadas a:

- retenção de clientes
- previsibilidade de receita
- eficiência contratual
- comportamento de clientes de risco
- impacto financeiro do churn

O objetivo inicial do projeto é desenvolver entendimento analítico do comportamento dos clientes e identificar padrões operacionais associados ao cancelamento.

---

## Objetivos Iniciais

O projeto deverá inicialmente focar em:

- entendimento estrutural do dataset
- validação da qualidade dos dados
- investigação exploratória
- identificação de padrões iniciais
- análise de possíveis fatores relacionados ao churn

Etapas futuras poderão incluir:

- feature engineering
- modelagem preditiva
- segmentação de clientes
- análises estatísticas
- scoring de risco
- recomendações estratégicas
